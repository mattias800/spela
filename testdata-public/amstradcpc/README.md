# Amstrad CPC PD test ROM

**Status:** placeholder — folder exists but no ROM shipped yet.

## What's needed

A small `.dsk`, `.cdt`, or `.sna` file that boots the libretro `cap32`
core and produces frames.

## Sourcing

The **CPCWiki** community archive (https://www.cpcwiki.eu) maintains
indexes of public-domain CPC software. The CPC demoscene is also
prolific and many productions are explicitly licensed CC0/CC-BY.

Pick a small one (a few KB), save it here, and add an entry in
`../ATTRIBUTION.md` with author + license + source URL.
