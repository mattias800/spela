# Amstrad CPC PD test ROMs

**Status:** includes one tiny CC0 boot fixture plus zero-byte filename
stubs for library-scan coverage.

## Boot fixture

`spela-hello.dsk` is generated by `scripts/build-testdata-roms.py`.
It is a minimal CPCEMU/extended DSK image with one CPC Data-format track
and a tiny AMSDOS BASIC file (`SPELA.BAS`). It is authored by Spela
contributors and dedicated to the public domain; see
`../ATTRIBUTION.md`.

Rebuild it from the repository root with:

```sh
python3 scripts/build-testdata-roms.py
```

## Filename stubs

The other files in this folder are zero-byte fictional Spela-branded
stubs. They exist only so scanner/library UI flows have multiple CPC
titles to index in fresh installs and CI. They are not launchable ROMs.

## Sourcing

The **CPCWiki** community archive (https://www.cpcwiki.eu) maintains
indexes of public-domain CPC software. The CPC demoscene is also
prolific and many productions are explicitly licensed CC0/CC-BY.

If a real third-party PD CPC title is added later, keep it small and add
an entry in `../ATTRIBUTION.md` with author + license + source URL.
