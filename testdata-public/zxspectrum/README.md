# ZX Spectrum PD test ROM

**Status:** placeholder — folder exists but no ROM shipped yet.

## What's needed

A small `.tap`, `.tzx`, `.z80`, or `.sna` file that boots the libretro
`fuse` core and produces frames.

## Sourcing

The community-maintained **World of Spectrum** archive
(https://worldofspectrum.org) has a "Public Domain" section with
verifiable PD/CC-licensed games and demos.

Pick a small one (a few KB at most), save it here, and add an entry
in `../ATTRIBUTION.md` with author + license + source URL.

Examples of historically-PD-released Spectrum games to look for: any
title released by `Crash` magazine's "Crashtape" sampler series whose
authors later relicensed it as PD; demoscene productions explicitly
released under CC0.
