Second Screen Keyboard & Trackpad — Approaches

How to structure the tabbed controls within the existing Controls page

A

Segmented Control at Top (Recommended)

A compact pill-style segmented control at the top of the Controls page, replacing the current P1/P2 port selector row. Tabs: Gamepad | Keyboard | Trackpad. The P1/P2 port selector moves inside the Gamepad tab content. Each tab fills the remaining vertical space below.

Pros

  • Familiar pattern (iOS/Android segmented controls)
  • Minimal vertical space used by the selector
  • Easy to add more tabs later
  • Quick switching — always visible

Cons

  • 3+ tabs on a small screen can get cramped
  • Always visible = less space for content
B

Bottom Tab Bar

A small icon-based tab bar at the bottom of the Controls page (like a mini navigation bar). Icons: 🎮 Gamepad | ⌨️ Keyboard | 🖱️ Trackpad. Content fills the area above. Tab labels shown below icons.

Pros

  • Thumb-friendly position (bottom of screen)
  • Icons are recognizable at small sizes
  • Scales well to 4-5 tabs

Cons

  • Eats into bottom area — conflicts with keyboard/trackpad layout
  • Might be confused with the pager's page indicators
C

Swipe Sub-Pager (Nested Pager)

The Controls page itself becomes a nested horizontal pager. Swipe left/right between Gamepad → Keyboard → Trackpad. Dot indicators at the bottom show which sub-page is active. No visible tabs — just swipe.

Pros

  • Maximum content space — no UI chrome for tab selector
  • Familiar swipe gesture (already used for the main pager)
  • Clean, minimal look

Cons

  • Nested pager inside pager — swipe conflicts between inner/outer pager
  • Discoverability: user might not know keyboard/trackpad exist
  • Trackpad needs swipe gestures itself — conflicts with pager swipes

Recommendation: Option A

The segmented control is the most practical for a small screen. It's compact, always visible for quick switching, and avoids the nested-pager swipe conflicts that would plague Option C (especially since the trackpad needs swipe/drag gestures). Option B's bottom tab bar would compete with the keyboard layout and the pager's page indicator dots.
