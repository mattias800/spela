Developer/Publisher Screen Restructure

The current screen has 11 sections in one endless scroll. How should we break it up?

Current sections (all in one scroll)

1. Hero Banner (logo + name + stats)
2. Company Description (about, founded, links)
3. At a Glance (stat cards carousel)
4. Top Rated Games (horizontal carousel)
5. Release Timeline (year-grouped history)
6. Rating Distribution (stacked bar chart)
7. Genre Breakdown (genre chips + counts)
8. Your Stats (personal play stats)
9. Games by Platform (full game list grouped by console)
10. Publishers (related publishers)
11. Related Developers

How should we restructure?

Click the approach that feels right

A

Tabs below the hero

Keep the hero banner always visible. Below it, add tabs: Overview (description, at-a-glance, top rated), Games (full game list by platform with filters), Stats (timeline, rating distribution, genre breakdown, your stats). Related developers/publishers become chips in the hero or overview tab.

Pros

  • Quick access to any section
  • Games list is its own focused view
  • Stats grouped logically

Cons

  • Tabs can feel heavy on mobile/gamepad
  • 3 tabs might feel like a lot
B

Two screens: Profile + Games

Main screen is a compact Profile with hero, description, at-a-glance stats, top rated row, and "View all games" button. Clicking "View all games" navigates to a dedicated Games screen with platform filters and the full list. Stats (timeline, rating dist, genre) are folded into the profile as compact cards. Related devs/publishers are chips at the bottom.

Pros

  • Clean, focused profile page
  • Game list gets a proper filterable screen
  • Feels natural — profile → browse games

Cons

  • Extra navigation step to see all games
C

Curated overview + "See more" links

Single scrollable screen but drastically shorter. Show only: hero, description, top 4 games as cards, 1-2 key stats inline, and "See all N games →" link. Each "see more" opens a focused subscreen. Think of it like an artist page on Spotify — a curated taste, not a data dump.

Pros

  • Feels modern and curated
  • No information overload
  • Progressively reveals detail

Cons

  • More subscreens to build
  • Some users want all data upfront

My recommendation: Option B — it's the simplest restructure that solves the scroll problem. The profile stays rich but manageable, and the games list becomes a proper browsing experience with filters. We already have the pattern from the console page (curated overview → filterable game list).
