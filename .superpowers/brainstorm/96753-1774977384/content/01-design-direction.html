Which design direction feels right for Spela?

How much of the logo's personality should bleed into the UI elements?

A

Subtle Glow

Keep form elements clean and dark, but add soft colored glows, translucent glass-effect containers, and subtle gradient accents. The logo is the star; the UI supports it without competing. Think: dark glass UI with warm lighting.

B

Neon Accent

Use the logo's color palette (blue, pink, orange, purple) as accent colors throughout — gradient borders on inputs, colorful focus states, gradient primary button. The UI picks up the energy of the logo. Think: retro-neon gaming aesthetic.

C

Minimal Dark

Ultra-clean dark UI with thinner, more refined inputs and buttons. Remove visual noise, increase whitespace, let the logo and gradient background do all the work. Think: premium dark app, Apple TV style.
