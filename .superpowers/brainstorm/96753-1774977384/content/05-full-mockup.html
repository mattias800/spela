Gradient background with SNES glow blobs, neon gradient inputs on focus, gradient fill + glow primary button. This is how both the Sign In and Add Server screens will look.

Component changes (app-wide)

SpTextField

  • Glass background (white 4-6% alpha)
  • Unfocused: subtle white border (8% alpha)
  • Focused: gradient border (blue→purple→pink)
  • Focused: outer neon glow shadow
  • Label: accent color when focused

SpButton

  • Primary: gradient fill (blue→purple→pink) + glow
  • Secondary/Outlined: gradient border + glow
  • Ghost: accent color text, no background
  • All: slightly larger border radius
