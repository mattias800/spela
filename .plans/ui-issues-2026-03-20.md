# UI Issues — 2026-03-20

## Issues reported by user

### 1. Explore page hero banner — game logo too small and not centered

### 2. Inconsistent gaps between cards across screens
- Home screen and Explore screen have different gaps between card sections
- Root cause: components add their own padding instead of parent controlling layout
- **Rule needed**: No component should EVER add padding to itself. Parent controls layout.
- **Rule needed**: Card section lists need a shared component that controls gaps.

### 3. Platform badge inconsistencies
- "Continue Playing" (Home) has one badge design
- Explore page banner has another
- Game detail heading has yet another
- **Rule needed**: ONE SpChip/SpBadge component used everywhere. No inline custom badges.

### 4. Console abbreviation overuse
- Only asked for abbreviation on cards with very long names ("Commodore Amiga", "Nintendo Entertainment System")
- Writing "GEN" instead of "Genesis" is confusing
- Should use full name everywhere EXCEPT when space is genuinely tight (small cards)

### 5. Text too small, insufficient line spacing
- Game card text is hard to read (e.g. "Advance Wars" + "GBA" in Top Rated)
- Need minimum text sizes and line spacing in the design system

### 6. Tab navigation animation wrong
- Clicking bottom tab bar should NOT animate the screen transition
- Gamepad L1/R1 navigation SHOULD animate
- Currently both animate

### 7. Developer Spotlight banner needs more polish
- Move "Developer Spotlight" title INTO the banner
- Add company logo if possible, not just text

### 8. "Visual Discovery" link pushes down content
- The "Browse Gallery" link is below the card heading, pushing the game list down
- Card heading should be a shared component with `rightContent` slot for links

### 9. Missing box art gradient looks bad on colored backgrounds
- Current: dark blue gradient placeholder
- Should be: transparent black overlay, to darken whatever background is behind it
- Same issue with "Top Developers" cards on console page

### 10. Console page section ordering and alignment
- "Top Rated" has different horizontal alignment than "Essentials"
- "Recently Played" should be FIRST (most relevant to user), not at the bottom
- "Browse All Games" should be near the top too

## Root Causes

1. **No enforced component discipline** — pages build custom UI instead of using Sp* components
2. **Components add their own padding** — should be parent-controlled
3. **No standardized layout components** — no SpSectionList, no SpScreenContent
4. **Inconsistent badge/chip usage** — same concept rendered differently across screens
5. **No minimum text size / line spacing rules** in the design system
6. **Code reviews don't catch design system violations** — needs explicit checklist
